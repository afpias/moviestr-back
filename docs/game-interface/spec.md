# SPEC-004: Игровой интерфейс

| Поле                 | Значение           |
| -------------------- | ------------------ |
| Статус               | реализовано        |
| Последнее обновление | 2026-10-14         |
| Зависимости          | SPEC-001, SPEC-003 |

## Цель

Как игрок я хочу видеть кадр и основные действия без визуального шума, чтобы сосредоточиться на угадывании фильма и
понимать состояние раунда на любом поддерживаемом экране.

## Композиция

- **UI-001.** Desktop-экран состоит из левой панели управления, центральной игровой сцены и правой информационной
  панели, визуально расположенных на общем тёмном фоне без разделительных border между областями.
- **UI-002.** Центральная сцена должна быть выровнена внутри доступной высоты viewport и не создавать вертикальный
  скролл страницы при стандартном desktop-размере.
- **UI-003.** Кадр является главным визуальным объектом, сохраняет пропорции и не растягивается по высоте контейнера.
- **UI-004.** Над кадром по центру располагаются пять компактных переключателей сложности.
- **UI-005.** Левая панель содержит выбор жанра, вертикальный список сложностей и действие «Перезапустить раунд».
- **UI-006.** Правая панель показывает только номер текущего кадра и формат «Изображения».
- **UI-007.** Название режима, призыв «Назови этот фильм», служебные уведомления и дублирующая метка кадра поверх
  изображения не отображаются.

## Цвет и состояния

- **UI-008.** Основной accent меняется вместе со сложностью: зелёный, жёлтый, оранжевый, красный, фиолетовый.
- **UI-009.** Активные контролы, прогресс и основное действие используют текущий accent; состояние не должно
  определяться только цветом.
- **UI-010.** При загрузке нового фильма сохраняется каркас из трёх областей, а skeleton появляется только в сцене.
- **UI-011.** Новый кадр не должен показывать текст `alt` до завершения загрузки изображения; после события `load`
  изображение получает осмысленный alt без ответа.
- **UI-012.** Ошибка загрузки заменяет центральную сцену понятным сообщением и кнопкой повторной попытки.

## Управление и результат

- **UI-013.** Под кадром располагаются пятисегментный прогресс, компактный combobox и основная кнопка действия.
- **UI-014.** Выпадающий список поиска открывается вверх, имеет непрозрачный фон и не перекрывается соседними областями.
- **UI-015.** После победы или поражения результат показывается на месте сцены, а не в modal/dialog.
- **UI-016.** Результат показывает постер полностью без кадрирования в едином формате `2:3`, локализованное название,
  оригинальное название и год.
- **UI-017.** Результат не содержит вводных фраз «Раунд окончен» и «Это был правильный ответ».
- **UI-018.** Победа содержит действие «Далее», поражение — «Повторить».

## Адаптивность и доступность

- **UI-019.** Минимальная поддерживаемая ширина viewport — 360 px; горизонтальный скролл страницы запрещён.
- **UI-020.** На узком экране боковые области перестраиваются, а переключатели сложности остаются доступными.
- **UI-021.** Основной сценарий полностью управляется клавиатурой и сохраняет видимый `focus-visible`.
- **UI-022.** Иконка без видимого текста имеет доступное имя; поле ввода связано с label или `aria-label`.
- **UI-023.** Ошибка сообщается текстом, а disabled/loading-состояния доступны assistive technologies.
- **UI-024.** Существенные анимации учитывают `prefers-reduced-motion`; обязательная анимация отсутствует.
- **UI-025.** Базовые controls берутся из локального реестра shadcn-vue; параллельные самописные реализации
  существующих компонентов не создаются.

## Сценарии приёмки

### AC-01: Смена сложности

- **Дано:** открыта игровая доска `easy`.
- **Когда:** пользователь выбирает `hard`.
- **Тогда:** каркас страницы остаётся на месте, сцена показывает загрузку, а accent становится оранжевым.

### AC-02: Загрузка изображения

- **Дано:** URL нового кадра уже получен, но изображение ещё не загрузилось.
- **Когда:** браузер рисует сцену.
- **Тогда:** старый кадр и текст alt не мигают; после `load` появляется новый кадр с корректным alt.

### AC-03: Результат

- **Дано:** раунд завершён поражением.
- **Когда:** состояние обновлено.
- **Тогда:** в центральной сцене целиком виден постер `2:3`, название, год и кнопка «Повторить».
