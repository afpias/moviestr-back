# SPEC-007: Публикация и серверный доступ к TMDB

Статус: реализовано и опубликовано 2026-10-18. Решение владельца: скрыть TMDB-токен и опубликовать приложение на Vercel.

## Требования

- **DEP-001.** Публичный сайт на Vercel открывает одиночную игру и клиентские маршруты, включая прямой вход в `/lobby`.
- **DEP-002.** Браузер получает данные через same-origin `/api/tmdb/*`, без TMDB Authorization и токена в сборке.
- **DEP-003.** Только сервер читает `TMDB_READ_TOKEN`; секрет не хранится в Git и не выводится в ошибки или логи.
- **DEP-004.** Прокси разрешает только GET к Discover, поиску и данным фильма, изображениям и альтернативным названиям.
  Хост TMDB фиксирован, параметры проверяются; произвольные URL, пути, ключи API и заголовки клиента не передаются.
- **DEP-005.** Ошибки конфигурации, провайдера, JSON и таймаута возвращаются с безопасным кодом без upstream body.
- **DEP-006.** Успешные ответы кэшируются CDN; ошибки не кэшируются. Одинаковые клиентские запросы дедуплицируются.
- **DEP-007.** `yarn dev` и `yarn preview` используют тот же серверный прокси и серверную переменную из локального `.env`.
- **DEP-008.** Деплой не меняет локальный характер мультиплеера и не добавляет учётные записи или сервер комнат.

## Приёмка и проверка

- При поиске Network показывает `/api/tmdb/search/movie`; в запросе браузера нет Authorization.
- Прямой переход на `/lobby` загружает приложение, `/api/tmdb/*` остаётся API, а не HTML fallback.
- Без серверного токена API отвечает 503 с безопасным сообщением; запрещённые запросы не вызывают TMDB.
- Сборка с контрольным `VITE_TMDB_READ_TOKEN` не содержит контрольный секрет в `dist`.
- Серверные unit-тесты проверяют валидацию, токен, кэш и ошибки; клиентские тесты — same-origin контракт.

## Границы

Изображения загружаются с публичного CDN TMDB. Прокси скрывает токен, но публичный read-only API доступен посетителям;
он не является авторизацией игроков или защитой ответов. Глобальное ограничение частоты запросов требует отдельного
решения; используются ограниченные параметры и CDN-кэш. Уже раскрытый ранее токен нужно заменить в TMDB.
