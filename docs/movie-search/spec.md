# SPEC-003: Поиск фильма и проверка ответа

| Поле                 | Значение                    |
| -------------------- | --------------------------- |
| Статус               | реализовано                 |
| Последнее обновление | 2026-10-14                  |
| Зависимости          | SPEC-001, TMDB movie search |

## Цель

Как игрок я хочу находить фильм по русскому или английскому названию и выбирать однозначный вариант, чтобы ответ не
зависел от языка интерфейса или совпадающих названий разных лет.

## Требования поиска

- **SRC-001.** Поиск не должен отправляться для строки короче двух символов после удаления внешних пробелов.
- **SRC-002.** Для запроса должны параллельно выполняться TMDB search с локалями `ru-RU` и `en-US`.
- **SRC-003.** Результаты объединяются по TMDB ID и ограничиваются десятью вариантами.
- **SRC-004.** Каждый вариант содержит русское название, английское название, год выпуска и стабильный ID.
- **SRC-005.** Варианты открываются над полем ввода и не изменяют геометрию игровой страницы.
- **SRC-006.** Запрос выполняется после debounce; устаревший ответ не должен заменять результаты более нового запроса.
- **SRC-007.** Ошибка поиска должна приводить к пустой выдаче и завершать локальное состояние загрузки без ошибки всей
  игры.

## Требования ответа

- **SRC-008.** Произвольный текст в поле не считается ответом; отправить догадку можно только после выбора объекта из
  автодополнения.
- **SRC-009.** После выбора фильма основная кнопка меняется с «Пропустить» или «Сдаться» на «Угадать».
- **SRC-010.** Перед сравнением название переводится в нижний регистр, `ё` заменяется на `е`, пунктуация и повторные
  пробелы нормализуются.
- **SRC-011.** Правильным считается только точное нормализованное совпадение с русским, английским, оригинальным или
  альтернативным названием загаданного фильма.
- **SRC-012.** Fuzzy matching и автоматическое исправление опечаток не применяются.
- **SRC-013.** Неверно выбранный фильм сохраняется в истории попыток текущего раунда.
- **SRC-014.** При повторном поиске такой вариант остаётся видимым, отображается серым с подписью «Уже выбрано» и не
  может быть выбран повторно.
- **SRC-015.** Переход к следующему кадру очищает поле и выдачу, но сохраняет историю неверных вариантов.
- **SRC-016.** Загрузка нового фильма очищает поле, выдачу и историю неверных вариантов.

## Состояния

```text
empty -> typing -> searching -> results
searching -> empty
results -> selected -> submitted
submitted incorrect -> empty with attempted IDs
new movie -> empty without attempted IDs
```

## Сценарии приёмки

### AC-01: Английский запрос

- **Дано:** пользователь вводит `matrix`.
- **Когда:** поиск завершён.
- **Тогда:** выдача содержит «Матрица», `The Matrix` и год в скобках.

### AC-02: Текст без выбора

- **Дано:** в поле введено название, но вариант не выбран.
- **Когда:** пользователь нажимает основную кнопку.
- **Тогда:** выполняется пропуск кадра, а текст не отправляется как ответ.

### AC-03: Повтор неверного варианта

- **Дано:** «Матрица» уже отправлена как неверный ответ в текущем раунде.
- **Когда:** пользователь снова находит «Матрицу».
- **Тогда:** вариант помечен «Уже выбрано», имеет disabled-состояние и не выбирается клавиатурой или мышью.

## Доступность

- Поле имеет доступное имя и управляется клавиатурой.
- Список использует семантику combobox/listbox из shadcn-vue.
- Disabled-вариант обозначается не только цветом, но и текстовой подписью.
