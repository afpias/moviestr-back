# План реализации SPEC-003

Статус: реализовано. Спецификация: [`spec.md`](./spec.md).

## Подход

Feature поиска объединяет русскую и английскую выдачу TMDB, удаляет дубликаты и возвращает единый тип результата.
Combobox допускает отправку только выбранного объекта; нормализованное сравнение выполняется в игровых правилах.

## Архитектура и данные

- `features/search-movie/api` — запросы TMDB по двум локалям и преобразование результатов.
- `features/search-movie/model` — debounce, отмена устаревших запросов и состояние поиска.
- `features/search-movie/ui` — shadcn-vue combobox и отображение прошлых попыток.
- `shared/lib/game-rules.ts` — нормализация и точное сравнение допустимых названий.

История неверных идентификаторов живёт в composable страницы до смены фильма. Список открывается вверх, сохраняет
клавиатурную навигацию и явно помечает недоступные варианты.

## Этапы

1. Реализовать двуязычный API и дедупликацию.
2. Добавить модель debounce и защиты от устаревшего ответа.
3. Собрать combobox и его состояния.
4. Подключить проверку ответа и историю попыток.

## Риски и проверка

Гонки поисковых запросов проверяются управляемыми Promise, а русские, английские и оригинальные названия — таблицей
unit-кейсов. Клавиатурное управление и disabled-варианты проверяются Vue Test Utils.
