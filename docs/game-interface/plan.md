# План реализации SPEC-004

Статус: реализовано. Спецификация: [`spec.md`](./spec.md).

## Подход

Маршрутная страница только собирает три самостоятельных widgets и передаёт им состояние сценария. Управляющие
действия остаются в features, предметное отображение — в entities, базовые controls — в `shared/ui`.

## Архитектура

- `pages/game/ui` — раскладка маршрута и связывание событий.
- `pages/game/model` — координация состояния страницы.
- `widgets/game-sidebar`, `game-stage`, `game-info` — левая, центральная и правая области.
- `features/show-round-result` — итог раунда на месте игровой сцены.
- `shared/assets` — tokens, темы и глобальный фон.
- `shared/ui` — локальные компоненты shadcn-vue.

CSS каждого компонента хранится рядом. Desktop использует трёхколоночную сетку без разделительных рамок; адаптивные
breakpoints перестраивают панели без горизонтального скролла. Accent задаётся CSS-переменной сложности.

## Этапы

1. Разделить страницу на widgets и features.
2. Собрать стабильную viewport-сетку и сцену изображения.
3. Реализовать состояния загрузки, ошибки и результата.
4. Добавить адаптивность, клавиатурную доступность и тесты.

## Риски и проверка

Высота кадров и разные пропорции постеров проверяются на desktop и 360 px. Component-тесты подтверждают сохранение
каркаса, смену accent, отсутствие мигания alt и действия результата.
